# Implementation knowledge

This directory tracks implementation knowledge that remains useful beyond one working session.

## Categories

- `plans/`: active, approved implementation plans.
- `specs/`: active requirements and designs awaiting implementation.
- `decisions/`: durable architectural or product decisions.
- `archive/`: selected completed plans, reports, and evidence with lasting value.

Create a category only when it has content. Except for structural `README.md` and `AGENTS.md` files, prefix filenames with the best-supported `YYMMDD-` creation date.

Temporary SDD material belongs in ignored `.superpowers/sdd/`. Sanitized raw reports, logs, diffs, and handoff evidence belong in ignored `.superpowers/archive/`; actual secrets and sensitive personal or operational data do not belong in either location.

See [AGENTS.md](AGENTS.md) for lifecycle rules and [archive/AGENTS.md](archive/AGENTS.md) before consulting historical material.
