  • 2026-now
    Jobcron

    Gathers entry-level developer postings from Korean job boards into one daily briefing, with an explained fit score for each post. A Go binary runs as an invite-only beta on EC2 and private RDS (PostgreSQL) managed with Terraform; its first production deployment was gated on restoring an encrypted backup. Built through harness engineering with multiple AI agents.

    국내 채용 포털에 흩어진 신입 공고를 매일 하나의 브리핑으로 모으고, 공고마다 근거가 설명된 적합도 점수를 제공합니다. Go 바이너리를 Terraform으로 관리하는 EC2와 프라이빗 RDS(PostgreSQL)에 배포해 초대 전용 베타로 운영하며, 첫 운영 배포는 암호화 백업 복원에 성공한 뒤 승인했습니다. 여러 AI 에이전트를 활용한 하네스 엔지니어링으로 개발했습니다.

    AI scoring used to need each user’s own LLM API key, and every post had to be scored quickly and cheaply. I chose an external question-answering model (TypeSafe Jev) for speed and cost: a paid probe on 30 synthetic posts measured a median 0.54 s and about USD 0.00013 per post. The server now asks it fixed yes/no and scored questions about each post through an API, under per-user and total daily US-dollar limits, with a deterministic fallback. It has been in production since October 30, 2026, and users no longer need an API key of their own.

    예전에는 사용자가 직접 LLM API 키를 넣어야 AI 평가를 받을 수 있었고, 모든 공고를 빠르고 저렴하게 평가해야 했습니다. 속도와 비용을 기준으로 외부 질의응답 모델(TypeSafe Jev)을 골랐고, 합성 공고 30개로 유료 측정한 결과 공고당 중앙값 0.54초, 약 USD 0.00013이 나왔습니다. 이제 서버가 API로 공고마다 정해진 예/아니요 질문과 점수 질문을 보내고, 사용자별, 전체 일일 USD 한도 안에서 운영하며 결정론적 폴백을 제공합니다. 2026년 10월 30일부터 운영 중이며, 사용자는 자신의 API 키 없이 평가를 받습니다.

    On November 3, 2026, SSAFY classmates using the alpha sent feedback and screenshots, alongside my own requests. An orchestrator agent specified them as 28 items with a plan; after my approval, worker and reviewer agents implemented and reviewed the work card by card. It shipped in two releases: an application-only release on November 6, and a migration release after a manual RDS snapshot on November 7, which became the beta release.     2026년 11월 3일, 알파를 쓰던 SSAFY 동기들이 보낸 피드백과 스크린샷, 그리고 제 요청을 반영해야 했습니다. 오케스트레이터 에이전트가 피드백을 28개 항목의 스펙과 계획으로 정리했고, 제가 승인한 뒤 작업자 에이전트와 리뷰어 에이전트가 카드 단위로 구현하고 검토했습니다. 애플리케이션만 바꾸는 릴리스(11월 6일)와, 수동 RDS 스냅샷 뒤의 마이그레이션 릴리스(11월 7일)로 나눠 반영했고, 11월 7일 릴리스가 베타 릴리스가 되었습니다. 그 결과 연봉, 위치, 기술스택을 보여 주는 공고 카드, 점수가 붙은 선호 조건과 비선호 조건, 저장 필터, 관리자 도구, SSAFY 동기들과 함께 고른 새 디자인을 11월 8일까지 병합해 배포했습니다.
